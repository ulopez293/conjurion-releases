# Conjurion — descargas

Aquí se publican los instaladores oficiales de **Conjurion**, el juego de estrategia por turnos de [Vindle Studio](https://vindlestudio.com).

## Descargar

1. Entra en [Releases](https://github.com/ulopez293/conjurion-releases/releases/latest).
2. Descarga `Conjurion-Setup-<versión>.exe`.
3. Ejecútalo y sigue el asistente. No necesita permisos de administrador.

Requisitos: Windows 10 u 11 de 64 bits.

## Qué incluye la beta

- Campaña de 7 etapas, partida contra la IA y partida local para dos jugadores.
- Las ocho facciones y un gestor de mazos.
- Es una beta de un jugador: todavía no hay juego en línea.

## Aviso

Este repositorio solo contiene instaladores; el código del juego no es público. El juego y sus recursos están protegidos por la licencia que aparece al instalar. Conjurion no es una versión oficial de PoxNora.
